# Сайт Юричу

## Фото

Все фотографии кладём в папку `photos/`.
Поддерживаемые форматы: `.jpg`, `.jpeg`, `.png`, `.webp`, `.heic`.

### `photos/vk/` — выгрузка работ из VK

Источник: [vk.ru/furniture174](https://vk.ru/furniture174) — «Мебель на заказ (Кухни|Шкафы-купе)», id сообщества `112382393`.
Выгружено 27.09.2026: **878 фото**, 1080 px по длинной стороне, ~265 МБ.

Имя файла — `<дата публикации в VK>_<id фото>.jpg`, так что всё сортируется по дате.

`photos/vk/index.json` — на каждый файл: альбом, id, дата, подпись из VK, размеры и ссылка на оригинал (до 2560 px).
Ссылки VK подписанные и со временем протухают, поэтому оригиналы при необходимости нужно перезапрашивать заново.

Одно фото (`-112382393_456239090`, альбом «Шкафы-купе», 2019 г.) не скачалось — CDN VK отдаёт на него 424 и по свежей ссылке; похоже, битое на стороне VK.
