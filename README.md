# Сайт мебельной мастерской · Челябинск

Статический сайт-портфолио: лендинг + каталог из 878 работ. Ни сборки, ни зависимостей —
это обычные HTML, CSS и JS, которые можно положить на любой хостинг.

```
index.html              главная: услуги, преимущества, этапы, контакты
works.html              каталог работ: фильтры по разделам, лайтбокс
assets/css/style.css    все стили
assets/js/main.js       шапка и год в подвале
assets/js/works.js      каталог: фильтры, подгрузка, лайтбокс
assets/data/gallery.json список фото для каталога (генерируется)
assets/thumbs/          превью 480 px (генерируются)
assets/img/             обложки разделов и фон первого экрана
photos/vk/              оригиналы фотографий, 1080 px
scripts/build_gallery.py пересборка превью и gallery.json
```

## Посмотреть локально

Каталог читает `gallery.json` через `fetch`, поэтому просто открыть `index.html` двойным
кликом не получится — нужен любой локальный сервер:

```bash
python3 -m http.server 8000
# затем http://127.0.0.1:8000/
```

## Опубликовать

Подойдёт любой статический хостинг. На GitHub Pages: **Settings → Pages → Deploy from a branch**,
ветка текущая, папка `/ (root)`. Файл `.nojekyll` уже лежит в корне.

## Добавить фотографии

1. Положить снимки в `photos/vk/<раздел>/` с именем вида `2026-09-27_12345.jpg`
   (разделы: `kuhni`, `shkafy-kupe`, `gorki`, `stoly`, `prihozhie`, `detskie`, `lenta`).
2. Выполнить `python3 scripts/build_gallery.py` — пересоберёт превью и `gallery.json`.
   Уже существующие превью не трогаются, так что прогон быстрый.
3. Поправить счётчики фото на главной (`index.html`, блок «Что мы делаем») и в заголовках.

Новый раздел добавляется в объект `CATS` в `assets/js/works.js` — название оттуда попадёт
в фильтры и лайтбокс.

## Контакты на сайте

Телефон, ссылки и адрес вшиты в `index.html` и `works.html` (шапка, блок «Посчитаем вашу
мебель», подвал, блок `application/ld+json`). Сейчас там данные из VK-сообщества:

| Что | Значение |
|---|---|
| Телефон | +7 908 704-65-81 |
| ВКонтакте | vk.com/furniture174 |
| Telegram | t.me/mebelchel74 |
| Instagram | @max_mebel_chel74 |
| Город | Челябинск, Ленинский район |

Формы заявки нет намеренно: статическому сайту негде принимать отправку, а телефон и
мессенджеры работают без бэкенда.

## Фотографии

Все фотографии лежат в `photos/`.
Поддерживаемые форматы: `.jpg`, `.jpeg`, `.png`, `.webp`, `.heic`.

### `photos/vk/` — выгрузка работ из VK

Источник: [vk.ru/furniture174](https://vk.ru/furniture174) — «Мебель на заказ (Кухни|Шкафы-купе)»,
id сообщества `112382393`. Выгружено 27.09.2026: **878 фото**, 1080 px по длинной стороне, ~265 МБ.

Имя файла — `<дата публикации в VK>_<id фото>.jpg`, так что всё сортируется по дате.

`photos/vk/index.json` — на каждый файл: альбом, id, дата, подпись из VK, размеры и ссылка
на оригинал (до 2560 px). Ссылки VK подписанные и со временем протухают, поэтому оригиналы
при необходимости нужно перезапрашивать заново.

Одно фото (`-112382393_456239090`, альбом «Шкафы-купе», 2019 г.) не скачалось — CDN VK отдаёт
на него 424 и по свежей ссылке; похоже, битое на стороне VK.
